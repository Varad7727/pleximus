# Pleximus AI Hackathon - Autonomous Tool-Calling Agent

An autonomous AI Agent built with the Google Gemini API that can reason through natural language requests and invoke Python tools dynamically.

## Features & Tools Implemented
1. **Calculator**: Evaluates local mathematical expressions safely.
2. **Weather Lookup**: Queries live weather from Open-Meteo API using coordinates.
3. **Text Utility**: Performs word count, char count, reversing, and casing operations.
4. **Wikipedia Summary**: Fetches article summaries via the Wikipedia REST API.
5. **Currency Converter**: Fetches live exchange rates via the Frankfurter API.
